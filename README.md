# Language Study Coach

一个可接入不同模型服务的本地英语学习应用。选择目标后直接开始日常练习，由 AI 根据真实答题记录逐步形成能力画像，并决定下一题的技能与难度。

## 本地运行

需要 Node.js 22.12+（本机已在 Node.js 24 上验证）。

```sh
npm install
npm run dev
```

打开 http://127.0.0.1:5173/ 。进入「模型设置」，可选择「本机 Codex」复用 ChatGPT 登录，也可填写其他服务商的 API 地址与 API Key，自动获取可用模型后自行选择。保存后测试连接。未连接真实模型时不会生成模拟成绩。

```sh
npm test          # 接口适配与学习流程测试
npm run build    # 构建前端
npm run preview  # 同一端口预览构建结果，也会启动本地 API
```

`dev` 与 `preview` 不要同时运行。此版本使用 Vite 中间件提供本机 API，不能只把 dist 上传到静态托管后就直接使用；尚未做公网部署和多用户服务。

## 已实现

- 可选的 Supabase 云端同步：邮箱验证码登录、开启前预览、自动同步、离线重试、修订冲突保护和暂停，网页与 iOS 共用。统一免费项目、数据库及专用发信服务已配置，真实收件、登录与联网同步已验证，普通用户无需填写项目参数，见 [启用说明](docs/cloud-sync.md)。

- 四类学习目标：四六级（内部切换四级 / 六级）、高中、初中、日常英语。
- 默认综合模式，另有听力、写作、阅读。每轮练习 5 题，可提前结束并生成画像；不提供初测或重测入口，尚无记录的能力显示「待积累」。
- 第一题单独生成；之后在提交回答时一次请求同时返回批改和下一题。模型根据目标、能力画像、最近记录、当前回答、提示与重播情况自主安排题型和难度。没有固定正确率阈值。
- 选择题卡、完整阅读材料、文字表达、连续话题对话、听力播放 / 暂停 / 重播 / 调速 / 原文。
- 浏览器语音转写，编辑后提交；可用性取决于浏览器、麦克风权限和语音服务。不做发音评分。
- AI 批改、解释、初步能力画像、学习小结、具体错题与同知识点再练。所有目标共用一份能力画像，切换目标只改变出题方向；已有分目标画像兼容读取，新小结更新统一画像，保留本轮未测能力的已有证据。
- 四级 / 六级显示独立的通过率估计条。数据不足显示待评估；至少 20 道无提示作答、阅读 / 听力 / 表达各至少 3 道才允许 AI 在小结中评估，AI 还需检查考试难度与写作翻译覆盖。结果以至少 20 个百分点宽的主观区间、理由和更新时间展示，未经过真实考试结果校准，不将正确率直接换算通过概率。
- 专项题型与名称一致：写作练习生成表达任务；阅读练习必须有完整文章且考阅读理解。旧对话、题卡记录继续兼容。
- 表达建议基于用户自己的原句做必要润色，保留原意、细节和叙述顺序，并解释修改依据；自由表达批改不向模型提供当前题的参考范文。参考答案仍可单独查看，选择题不提供句子润色。
- 学习页采用连续聊天布局，题目、作答、批改与追问按发生顺序保留，底部输入。可切换「作答 / 问教练」，用中文或英文澄清原意、询问词义或语法，也可以追问本轮前面的题目。答题前求助会记录辅助使用；追问不重复计分，不丢弃已准备的下一题。
- 可按用户要求整理并导入旧聊天的学习背景，保留来源、原始回答摘录、已练内容、薄弱点和学习安排，该背景仅供后续 AI 参考，不在页面显示。所有目标共用学习背景，后续出题、批改和小结结合当前目标参考；历史自述成绩不当成当前测评，旧聊天不转换为软件的做题数或时长。当前导入由本地 API 完成，不作为通用用户入口；手机独立版不提供导入功能。
- 批改时同时准备下一题，点击「继续下一题」直接取出服务端暂存题；刷新后仍可继续。下一题及其答案在切换前不发送到浏览器。最后一题不额外出题；若下一题格式异常，保留本次批改并提示点击继续时重新生成。
- 小结页逐题回顾：答对与答错的题目都可以展开，查看完整材料、选项、自己的回答、参考答案、解析和辅助使用记录。
- 本机持久化学习记录，刷新恢复当前题；作答草稿保存在当前浏览器标签页。重复提交不重复批改或计数。
- 学习时长来自实际前台作答计时，AI 等待与后台时间不计入；无交互 60 秒后暂停，播放音频 / 转写时继续计时。只累计已提交题目，每题最多 30 分钟。它是近似活跃时间，不是精确专注度测量。
- 明确处理认证失败、限流、超时、缺失题目材料、重复题目、格式异常与答案矛盾，不回退到伪造的 AI 结果。

## 模型接入

| 选项 | 协议 | 配置方式 |
| --- | --- | --- |
| 本机 Codex | 官方 app-server / stdio | 复用本机登录，或通过官方页面 / 设备码授权；无需填写 Key |
| OpenAI | Chat Completions | 填写 Key，获取模型后选择 |
| DeepSeek | OpenAI 兼容 | 填写 Key，获取模型后选择 |
| OpenAI 兼容接口 | Chat Completions | 填写基础地址与 Key，获取模型后选择 |
| Anthropic | Messages | 填写 Key，获取模型后选择 |
| Google Gemini | generateContent | 填写 Key，获取模型后选择 |

模型需能遵循提示返回 JSON。兼容接口的具体模型支持程度仍取决于供应商，不代表所有厂商均已实测。当前保存一套有效配置，切换服务商或地址需要重新输入密钥。

填好地址和密钥后自动读取上游模型列表；已有 API 配置再次进入设置也会自动读取。支持搜索、刷新及手动填写模型 ID，不会自动替你选择或切换模型，点击「保存配置」才生效。获取失败时保留当前模型并显示原因。网页与 iOS 共用此功能，详情见 [模型列表](docs/model-discovery.md)。

接口实现参考官方文档（2026-11-14 核对）：[OpenAI](https://developers.openai.com/api/reference/resources/chat)、[Anthropic](https://platform.claude.com/docs/en/api/messages/create)、[Gemini](https://aistudio.google.com/api-reference/generate-content/generate-content)。

### 使用本机 Codex

1. 安装官方 Codex CLI，使其在 PATH 中可用。本机已用 `codex-cli 0.162.1` 验证。
2. 进入「模型设置 → 本机 Codex」。已在 Codex 中登录 ChatGPT 时，页面直接显示已授权状态和脱敏账户。
3. 未登录时选择「ChatGPT 授权登录」，点击官方链接，在官方页面完成登录，再回到学习软件。也可选择「使用设备码登录」。页面自动检查完成状态，可取消未完成的授权。
4. 选择学习模型或保留 Codex 默认模型，点击「使用这个 Codex」，再测试连接。

模型列表来自 Codex，访问权限和额度由实际账户决定。使用的是 Codex 账户额度，不保证免费或不限量。登录由 Codex 管理，应用不读取 `auth.json`，不复制令牌。授权登录本身不读取历史聊天；学习背景由用户要求时另行整理导入。新授权会更新本机共享的 Codex 登录；切换学习服务商不会退出 Codex。

学习请求单独指定思考强度：出题、批改、题内追问和连接测试使用 `low`，学习小结使用 `medium`。仅覆盖当前学习请求，不继承全局的高强度编程设置，也不修改本机 Codex 的全局配置。模型仍使用页面选择的模型；选择默认模型时沿用本机 Codex 默认模型。

后端启动独立 app-server 子进程，通过标准输入输出通信；每次请求使用临时线程和只读沙箱，关闭命令执行、网页搜索、MCP 和插件等工具入口，不修改全局 Codex 配置。失败或超时不保存结果，超时中断请求，服务关闭时清理子进程。可在启动前设置 `CODEX_CLI_PATH` 指向原生 Codex 可执行文件，供非标准安装位置使用。

此方式用于本地个人应用。官方说明 app-server 认证不允许用于商业或托管服务，并建议第三方应用迁移到 Sign in with ChatGPT；若以后开发托管产品，应先重新设计授权接入。[官方 app-server 文档](https://learn.chatgpt.com/docs/app-server)、[认证文档](https://learn.chatgpt.com/docs/auth)（2026-11-14 核对）。

## 数据与隐私

学习记录和 API Key 保存在 `.local/state.json`，已被 Git 忽略，开发服务器禁止直接读取 `.local` 目录。Key 仅由本机后端发送给所配置的 API 地址，页面只能读取是否已保存，不会收到已保存的 Key。更换地址时不会沿用旧 Key；不跟随 API 重定向。

该文件为本地明文，不提供系统钥匙串加密。备份学习数据时请妥善保管此文件，不要分享或提交。页面不读取历史演示版的虚构学习记录。

服务默认仅监听 127.0.0.1，并检查 Host、Origin 和 JSON 请求标记。网页版后端按单机个人应用运行；云同步账号不提供本机服务的公网访问控制。不要直接对外暴露开发端口。

题目和答题内容会发送给所选模型服务。听力当前使用系统语音；浏览器语音转写可能调用浏览器厂商的服务。API 按供应商规则计费，Codex 使用已登录账户的额度。

## 主要文件

- `src/main.js`：页面、交互、浏览器语音和前台计时。
- `src/chat.js`：聊天消息时间线、题目、批改、追问与底部输入。
- `src/style.css`：桌面和移动端布局。
- `server/api.js`：电脑版 HTTP 接口和磁盘存储。
- `server/engine.js`：电脑和手机共用的会话、批改、追问和画像逻辑。
- `src/native-client.js`：手机独立运行适配及原生 API 请求。
- `ios/`：Xcode 工程与加密存储插件。
- `server/profile.js`：统一能力画像、旧数据兼容与考试样本统计。
- `src/icons.js`：本地 SVG 图标和练习名称。
- `server/background.js`：带聊天来源的学习背景结构校验。
- `server/providers.js`：供应商协议、认证和错误处理。
- `server/codex.js`：Codex 子进程、官方授权、模型列表和临时学习请求。
- `server/coach.js`：出题 / 批改 / 画像提示与结果校验。
- `tests/coach.test.js`：接口与核心学习流程测试。
- `docs/product-outline.md`：产品范围与后续方向。
