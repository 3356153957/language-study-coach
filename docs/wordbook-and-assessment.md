# 单词本与主动评估（2026-11-18）

## 功能

- 阅读原文中的英文单词可以点击收藏、再次点击取消；同词重复出现时一起高亮，单词本合并展示并保留原句和来源。
- 单词本在英文下方突出显示中文释义，原句下方显示中文翻译，支持中英文搜索、待学习/已掌握筛选和移出。
- 已连接 AI 时，进入单词本会补充最多 8 个缺少释义的词；其余词可逐条获取。释义根据原句生成并保存，失败显示提示，可重试，收藏不丢失。
- 四级、六级通过率改为点击后由 AI 评估。显示两位小数、评估依据、时间和与上次的变化；失败保留旧结果。学习小结不再自动更新通过率。
- 记录纳入备份和既有云同步合并规则。正在练习中的收藏先保存在本机，结束本轮后随练习记录同步；不需要修改云数据库。
