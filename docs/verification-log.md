# 验证记录

按时间整理的历次验证结果，最新的放在各平台文档中：[桌面版](desktop.md)、[SwiftUI 手机端](ios-swiftui.md)、[iOS 1.x](ios.md)、[云同步](cloud-sync.md)。数字是当时的测试数量，不代表当前版本。

- 上游模型列表、自适应题组、同步防滥用与更新检查（2026-11-15）：78 项本地测试通过，覆盖五个 API 选项、分页、密钥隔离、原生 GET 请求、错误处理、模型选择，B1 阅读 / 听力同材料多问题、文字表达多输入格、授权回调恢复、邮箱验证码限频 / CAPTCHA token、GitHub Release 检查和答案隐藏。隔离浏览器已验证自动获取、搜索、选择保存、手动输入、失败提示和切换服务商。厂商协议使用模拟响应验证，未用真实 API Key 逐家请求。
- iOS 1.4（build 5）：私有仓库云构建成功，78 项测试、Swift 编译、Xcode archive 和 IPA 下载核验通过。Release 与校验记录见 [iOS 说明](ios.md)。IPA 未签名；Turnstile 需要维护者配置站点 Key 与 Supabase Auth Secret，私有 GitHub Release 不能被 App 匿名读取。
- iOS 1.4.1（build 6）补充 OpenAI 地区限制的明确错误提示；不绕过官方地区政策，受限地区可改用 API Key 服务商。
- iOS 2.0 SwiftUI 迁移（2026-11-16）：91 项 Node 测试、网页构建和无页面引擎打包通过；另在 Xcode 26.3 通过 iPhoneOS archive、7 项原生 XCTest 和 3 项 UI 测试，导出并校验 2.0.0（build 8）未签名 IPA。已检查竖屏/横屏键盘、反馈和验证码错误/改正截图，并修复横屏回答被工具区遮挡的问题。签名与真机验收待完成，见 [迁移状态](ios-swiftui.md)。未发布 1.4.2 修补包。

- 可选云同步（2026-11-15）：64 项本地检查通过，含真实 PostgreSQL 的 RLS / 修订检查、双设备与离线重试、暂停中断、官方 SDK 登录刷新协议和跨站拒绝。统一 Supabase 项目及 SMTP 已部署，实际 SQL 权限检查及匿名 HTTP 拒绝通过；独立测试邮箱已完成真实收件、验证码登录、联网上传合并与暂停，正式网页邮箱入口也已核验。iOS 1.3（build 4）已通过 63 项云构建测试并生成内置统一公开配置的未签名 IPA，签名安装和真机同步尚未验证，详见 [配置说明](cloud-sync.md)。

- iOS 适配与数据迁移（2026-11-15）：53 项测试通过，新增 ChatGPT 独立订阅授权及本机凭据保护、学习备份导入导出、稳定 ID 合并与保存失败回滚。已实测网页文件预览、合并和下载，并打开官方登录页；真实账号授权及真机迁移仍需本人操作。iPhone 16 Pro 安全区域已有原生模拟器截图验证，手机常驻品牌栏已移除。

- 首次 IPA（2026-11-15）：私有仓库云构建成功，测试、Swift 编译及 Xcode archive 通过；未签名 IPA 已下载，包完整性、iPhoneOS arm64 架构和最新听力修复资源核验通过。签名及真机测试尚未完成。

- 手机独立版与入口优化（2026-11-15）：38 项测试、网页构建和 Capacitor 同步通过；正式页面确认不再显示学习背景、初测或重测入口。390px 隔离页面验证了慢请求立即反馈、失败重试、聊天首题滚动和题目就绪后自动进入。原生存储 Swift、Xcode 编译与 IPA 安装尚未验证，详见 iOS 说明。

- 自动化：38 项测试通过，覆盖五个 API 服务选项、Codex 登录复用 / 浏览器和设备码授权协议 / 取消、账户脱敏、临时线程、学习任务思考强度、工具请求拒绝、失败与超时中断、跨站拒绝、6 题测评闭环、原句润色输入、批改同时备题、暂存题不提前泄露、取题不再次调用模型、异常备题恢复、幂等提交、并发冲突、持久化恢复、新增追问上下文与幂等保存、求助标记、失败回复回滚、历史背景导入去重、跨目标共享画像与学习背景、旧画像兼容、专项题型约束、通过率估计校验和 AI 教学质量门槛。新授权分支使用模拟协议测试。
- 浏览器：隔离模拟接口下完成「设置 → 测试连接 → 6 题初测 → 小结 → 错题回顾」，验证了选择题和文字草稿刷新恢复、阅读材料、对话继续、听力速度与暂停控件。
- Codex 实测：本机已有 ChatGPT 登录成功复用，网页完成「启用 → 连接测试」。另用 `npm run verify:codex` 完成 6 题真实初测，覆盖语法、阅读、听力、词汇和表达，包含一题故意答错；小结、五项能力画像、持久化恢复、重复提交幂等和错题再练均通过。共 14 次真实模型调用，验收数据在独立临时目录，未写入正式 `.local/state.json`。
- 批改合并出题实测（2026-11-15）：在独立验收环境中，一次 GPT-6.1-Sol / low 调用约 16.7 秒完成示例原句润色和下一题生成；页面显示备题完成，点击后直接进入下一题，无再次模型调用。该耗时为单次样本，不代表固定等待时间。
- 聊天与背景导入（2026-11-15）：24 项测试及构建通过；真实 Codex 追问把“准备菜肴”的误解修正为“提前把盘子摆在餐桌上”；浏览器验证聊天消息、快捷取下一题和 390px 窄屏无横向溢出。正式页面显示已导入背景，原有会话与画像保持一致。
- 共享画像与练习入口（2026-11-15）：29 项测试及构建通过；实际页面切换四级、六级、高中和初中时共用同一画像，非考试目标隐藏通过率面板。验证四个入口及图标、考试「待评估」状态和 390 × 844 窄屏布局，无横向溢出；未向正式数据写入验收答案。截图位于 `artifacts/shared-profile-modes.png`、`artifacts/shared-profile-mobile.png` 和 `artifacts/shared-profile-exam.png`。
