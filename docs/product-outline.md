# Language Study Coach 产品大纲

## 产品目标

让不同需求的人迅速找到适合自己的学习入口。AI 根据具体表现持续认识学习者，决定练什么、怎么解释、何时加难或拆开知识点。

## 首版入口

只保留四个学习目标：四六级、高中英语、初中英语、日常英语。四六级内部选择四级或六级，不增加独立首页预设。

目标与练习方式分开。综合是默认练习方式；听力、写作、阅读是三个专项入口。所有目标共用同一份英语能力画像与学习背景；切换目标只调整选材、题型和训练侧重，进行中的学习可继续。本轮未测的能力保留原有证据，画像随实际学习更新。

## 首次使用

1. 选择学习目标。
2. 连接本机 Codex（复用已有登录或官方授权），或配置自己的 API；未连接模型不生成模拟结果。
3. 直接开始日常练习。AI 参考已有回答调整内容，逐步积累词汇、语法、阅读、听力和表达的证据。
4. 练习小结更新能力画像、判断依据与下一步建议。早期证据有限，尚无记录的能力明确显示「待积累」。

不设置初测或重测入口。能力画像随日常练习小结更新，尚无证据的能力显示「待积累」。

## 自适应学习

综合模式每轮默认 5 个任务，逐个生成。AI 综合学习目标、先前画像、最近 30 条跨目标、跨轮记录、当前整轮记录、答题对错、具体错误、提示、听力播放与查看原文情况，选择下一题技能和难度，并向用户说明原因。

不使用「最近 5 题高于 80% 加难、低于 50% 降难」等硬阈值，也不固定薄弱项出题比例。阅读弱可以多练阅读，听力弱可以增加听力，但 AI 应适当交叉能力、避免重复题目。

开放题允许多种正确表达，区分真正错误与可选表达优化。对话题接续用户话题，保留原意。代码负责结构有效、材料完整、重复提交和计数正确，教学判断交给模型。

表达建议从用户原句出发，保留观点、细节、句式和叙述顺序，修正拼写、语法、标点与自然度，并说明修改依据。自由表达批改时不提供当前题的参考范文，避免按范文重写；参考答案作为另一种写法单独展示。

提交回答时在同一次 AI 请求中完成批改，并依据当前回答的批改结果生成下一题。下一题先保存在服务端，用户看完解析点击继续时直接切换，刷新后仍可取出。最后一题只批改；若备题格式异常，保存已有批改，明确提示继续时重新生成。

四级、六级各自展示通过率估计条，以 425 分为备考目标。至少 20 道无提示作答，且阅读、听力、表达各至少 3 道后，AI 才能在小结中检查材料难度与题型覆盖是否足够；证据不足继续显示待评估。有效结果显示主观区间、具体依据和日期，尚未经真实考试结果校准。

## 交互

学习页去掉侧栏，以单条聊天记录展示题目、用户回答、批改和追问，底部放输入框。答题前可切换「作答 / 问教练」，批改后直接继续讨论，也可追问本轮旧题。中文澄清原意后，教练据此解释词义并改进表达。求助不自动重评或重复计数，讨论记录跟随题目保存；答题前求助作为辅助记录供批改参考。

- 选择题：按钮选项、选中状态、提交后解析。
- 阅读：完整短文与题目一起展示。
- 文字与对话：自由输入；浏览器支持时可用英语语音转写，转写后编辑再提交。
- 听力：系统英语语音、播放 / 暂停 / 重播、0.75 / 1 / 1.25 倍速、原文展开。
- 提示与原文：允许查看，记录使用情况供 AI 参考。
- 等待与错误：明确显示模型处理中；失败保留当前回答，可重试。
- 暂停学习：回到首页，之后继续同一题。可提前结束并根据已提交记录生成小结。

## 学习沉淀

保存题目、用户答案、解析、辅助使用、实际前台作答时间、模型来源和日期。能力画像每轮更新，显示证据与局限。错题按具体题目保存，支持查看原回答与解析，并围绕原知识点出新题。

每轮小结支持逐题展开回顾，保留答对和答错的题目、完整材料、回答与解释。历史小结同样可以回看，不需要再次请求模型。

不虚构学习时长、等级百分比、正确率或未观察到的能力。不从文本转写推断发音质量。

授权导入的旧聊天作为独立学习背景保存，包含目标、已练知识点、观察到的能力、薄弱点、学习安排和带来源的用户回答摘录。页面不展示导入背景，后续 AI 请求共用背景并参考当前学习目标。历史自述考试成绩保留为自述信息；不从旧聊天虚构当前等级、题数、正确率或有效时长。当前由本地导入接口写入，不自动抓取或同步其他聊天。

## 首版技术范围

本地网页 + Node.js 后端，学习记录保存在本机。支持本机 Codex 授权登录，以及 OpenAI / DeepSeek / OpenAI 兼容接口、Anthropic、Gemini 原生协议。Codex 凭据由官方 CLI 管理；其他接口由用户输入模型 ID 和 Key。当前只保存一套有效配置。

语音输入依赖浏览器能力，听力先用系统朗读。真实厂商质量需在用户配置后验证。先准备 iOS 独立版，直接使用厂商 API、本机加密保存；独立 ASR / TTS、发音评估、云同步、多用户、PWA 和桌面端留待后续。

## 后续优先级

1. 使用实际模型做教学质量验收：题目准确性、难度连续性、纠错是否尊重原意、综合模式能否照顾薄弱点。
2. 按使用反馈优化对话体验，增加可选的语音服务商。
3. 错题复习安排和更长期的能力变化记录。
4. 优先生成并真机验证 iOS IPA；无 Mac 时使用 macOS 云构建，签名需另行配置。
