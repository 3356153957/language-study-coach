# 界面更新 · 2026-11-19

本轮按用户确认的“更简洁、更克制”方向完成网页和 Electron 共用界面，采用暖白底、低饱和绿色、统一的细边框和焦点状态。没有修改 SwiftUI 原生界面。

## 主要调整

- 首页先展示今日练习、累计数据、专项入口，再展示推荐复习。能力画像、周进度、学习安排放在辅助栏；每日正确率仍可在近 7 天详情查看。
- 大屏使用侧栏，中屏使用顶部导航，小屏使用底部导航。详细页面提供返回路径。
- 设置拆成模型连接、云端同步、学习数据三个二级入口。原有网页原生容器中的更新入口继续保留。支持方向键、Home、End 切换；切换不清空未保存的输入。
- 统一设置表单、能力展开面板、错题、单词本、题卡、作答/问教练切换的描边、圆角、悬停、选中和焦点状态。练习中的已批改选项保持可读。
- 浏览器检查时发现无当前题目时保存草稿会访问空对象，已补充空值保护。

## 本地验证

- 158 项 Node 测试全部通过。随后调整周详情后，相关 23 项测试再次通过。
- Vite 生产构建通过。
- Playwright 使用临时目录中的模拟记录，实测设置分类鼠标和键盘切换、未保存输入保留、模型列表失败提示、能力面板展开、错题展开、空单词本、周详情和学习安排。
- 实测阅读练习选择答案、提交批改、下一题、切换作答/问教练时保留输入，以及结束本轮。
- 首页检查 375、768、1024、1440 像素宽度，无页面横向溢出。手机练习区输入框在视口内，聊天内容独立滚动。
- 375 像素宽度下实测四六级 10 空、15 选项词库和选择状态，无页面横向溢出。
- 最终浏览器操作未出现 JavaScript 页面异常。

以上为界面阶段的本地模拟接口和浏览器验证；未重新执行真实模型、云同步或 iOS 真机验证。随后已生成 Windows 1.0.5 安装包并完成本机覆盖升级，详见 [桌面版验证记录](desktop.md)。
