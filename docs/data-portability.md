# 学习数据迁移

在设置中点击“导出备份”，保存生成的 JSON。目标设备点击“导入备份”，选择文件，检查新增、更新、跳过和冲突数量，再确认合并。文件可能含有私人的回答和追问，导出文件不加密，请自行保管。

格式为 `language-study-coach`、版本为 `1`。包含练习题、回答、批改、追问、进行中的练习、共享能力画像及已有的历史学习背景。API 配置、API 密钥、ChatGPT/Codex 令牌和考试通过率估计缓存不导出。导入后保留目标设备模型配置；账号授权需要在各设备分别完成。

导入最多 20 MB、10,000 轮练习。格式、题目材料、答案一致性、时间、ID 和当前轮结构校验失败时整份拒绝。保存失败时不会提交内存中的新状态。相同 ID 不重复增加题量；只有已完成轮次具有相同回答前缀且备份中含更多回答时才更新，其他冲突保留本机内容。已有当前练习时，不再引入另一轮进行中的练习。导入不调用 AI。

已加入可选的 Supabase 云端同步，默认关闭，需配置项目并用邮箱验证码登录后主动开启。支持修订检查、离线重试、冲突保留和暂停；配置及验证边界见 [云端同步](cloud-sync.md)。ChatGPT 订阅登录仅用于模型使用权限，学习同步使用独立账号。
